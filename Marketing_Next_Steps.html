47-day launch sequence (after gates clear)

Pulled directly from §11 of the marketing plan. Begin Day 1 only after every blocking gate above is closed.

Pre-launch (this week)

  • Client fills Client_Onboarding.html
  • Engineering drops in landing-config.js
  • QA every page on mobile + desktop
  • Set up Search Console, GA4, server logs

Mon — Foundation

  • Landing pages live
  • Submit Google Search ads for review
  • Launch educational organic posts
  • Support team scripts ready

Tue — Google Search

  • Turn on high-intent campaigns
  • Conservative budget ($250–$500/day total)
  • Hourly disapproval / policy check
  • Live negative-keyword updates

Wed — Meta test

  • 3 educational creatives only
  • $50–$150/day initial
  • 18+ targeting; broad geo within served states
  • No before/after, no body-shame copy

Thu — Conversion review

  • CPC, quiz-start rate, qualified-lead rate
  • Fix friction (mobile form, CTA visibility)
  • Pull approval reasons

Fri — Expand winners

  • Increase budget on qualified-lead ad groups
  • Pause low-intent / expensive broad terms
  • Add real chat/call FAQs to /glp1-faq

Weekend — Trust

  • Publish 3–5 SEO articles
  • Record clinician explainer videos
  • Spin up "switching providers" segment

Week 2 — Scale

  • Add Brand-name pricing page if approvals allow
  • Test TikTok organic + Spark
  • Begin remarketing IF privacy counsel approves
