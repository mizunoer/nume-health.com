Nume Health SVG + Transparent PNG Kit
=====================================

Contents:
- /transparent-png : PNG files with transparent backgrounds
- /svg             : SVG files matching the PNG assets

Important note:
These SVG files were created from the raster logo assets available in this chat.
That means they are SVG-format files intended for compatibility/workflow use, but
not native hand-drawn vector source files like an original Illustrator build.
They should import into Figma and most design tools.

Included logo variants:
- primary horizontal
- reversed horizontal
- stacked
- mark only
- app icon
- social avatar
- website header
- email signature
