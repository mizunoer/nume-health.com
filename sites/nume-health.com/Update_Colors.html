Nume Health — Color System Recommendations

This page audits every color currently in use across nume-health.com and recommends a single, brand‑kit‑aligned palette. The goal is design continuity: every button, link, hover, badge, hero, and form on every page should resolve to a known token from the table below.

1. Summary & recommended palette

Recommendation

Adopt the Brand Kit palette (sampled from the actual logo gradient) as the single source of truth. Keep three brand‑guide tones — Mint, Off‑white, and Slate — as supporting surfaces and body text because they have stronger contrast / softer feel than the kit's slate gray.

  • Primary CTAs and links → Nume Blue #0077B6
  • Hover / secondary → Nume Cyan #00A6C8
  • Highlights, accents, success states → Nume Teal #12C8B8
  • Dark backgrounds, headings → Deep Navy #101D31
  • Body text → Slate #2E3E50 (kept from brand guide for contrast)
  • Page surface → Off‑white #F7FAFC

5. CSS tokens (drop‑in)

This snippet is what's already in assets/css/nume-health.css. It overrides the legacy --tg-* template variables and exposes a clean --nume-* API for new components.

:root {
  /* Brand Kit — derived from logo */
  --nume-blue:        #0077B6;
  --nume-cyan:        #00A6C8;
  --nume-teal:        #12C8B8;
  --nume-navy:        #101D31;
  --nume-slate-gray:  #7A8794;

  /* Brand Guide — supporting tones */
  --nume-mint:        #D8F7F2;
  --nume-offwhite:    #F7FAFC;
  --nume-slate:       #2E3E50;
  --nume-white:       #ffffff;
  --nume-border:      #E2E8F0;

  /* Semantic aliases */
  --nume-primary:      var(--nume-blue);
  --nume-primary-dark: #005f92;
  --nume-accent:       var(--nume-teal);
  --nume-accent-dark:  #0fa898;
  --nume-link:         var(--nume-blue);
  --nume-link-hover:   var(--nume-cyan);
  --nume-heading:      var(--nume-navy);
  --nume-text:         var(--nume-slate);

  /* Brand gradients */
  --nume-gradient:      linear-gradient(135deg, var(--nume-blue) 0%, var(--nume-cyan) 50%, var(--nume-teal) 100%);
  --nume-gradient-dark: linear-gradient(135deg, var(--nume-navy) 0%, #0f2842 50%, var(--nume-navy) 100%);

  /* Override Suxnix template */
  --tg-primary-color:    var(--nume-blue);
  --tg-secondary-color:  var(--nume-teal);
  --tg-heading-font-color: var(--nume-navy);
}

8. How to apply

  1. CSS tokens — already in assets/css/nume-health.css. Confirm it loads after style.css on every page.
  2. Migrate hardcoded hex — for any new component, prefer var(--nume-*) over a raw hex.
  3. Search & replace — for the literals #0B1B2B, #1BB6A8, #FAA432, #0A5DB8, #777777, #222222 still appearing in custom CSS, replace with the variable shown in §3.
  4. SVG assets — favicon and inline shapes should reference brand colors (or use currentColor and inherit from CSS).
  5. QA pass — visit each public page and the patient portal mocks, hover every interactive element, and confirm the rendered color matches §4.
Open question: for the patient portal (logged-in surfaces), do we keep the same palette or introduce a slightly different "calm" scheme (e.g. Mint surfaces + Navy text)? Recommendation: same palette, but lean on Mint and Off-white for surface tones to reduce visual fatigue during long sessions.
